📚 Library Inventory Manager Python Lab Assignment 03 – vedansh rawat

A simple command-line based Library Inventory Manager built using Python. This project helps manage books in a small library with features like adding books, issuing/returning books, searching, and storing records in a JSON file.

⭐ Project Overview

This project demonstrates:

Object-Oriented Programming (Book class, Inventory class)

JSON file handling for saving and loading catalog data

Error & exception handling for missing or corrupted files

Logging for better debugging and execution tracking

A fully interactive CLI menu

Proper Python package structure

It is built exactly according to the specific
ations of Python Lab Assignment 03.

🧠 Features

✔ Add new books (Title, Author, ISBN) ✔ Issue a book ✔ Return a book ✔ View all books ✔ Search by title ✔ Search by ISBN ✔ Data stored permanently in books.json ✔ Handles corrupted/missing files ✔ Logging using Python’s logging module ✔ Clean and modular package structure
